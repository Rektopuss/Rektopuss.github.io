# Florida secret placeholder artwork

Created with the built-in image-generation tool for the donations landing page. The generated PNG originals were exported to JPEG for the site. These are temporary themed images, not confirmed trip photography.

- `secret-placeholder.jpg`: used for locked secrets and the next reveal.
- `florida-placeholder.jpg`: used for unlocked placeholder cards.

Reveal titles and descriptions can be replaced in `donations/campaign-goals.js`, shared by the landing page and OBS overlays.

## Generation prompts

### Secret image

Use case: stylized-concept. Asset type: placeholder artwork for a Florida travel fundraising website secret-unlock card. Create one cinematic landscape image, 3:2 composition. A mysterious large rectangular object entirely concealed beneath dark navy satin fabric on a plinth, framed by silhouetted Florida palms at twilight. Subtle electric blue and purple rim lighting, deep black navy background, a tiny pink sunset glow. Centered covered object stays legible in a small portrait crop. Sophisticated realistic 3D illustration like a premium adventure reveal teaser. No text, no question marks, no locks, no logos, no watermark. The site will overlay its own question mark.

### Florida image

Use case: stylized-concept. Asset type: placeholder artwork for unlocked Florida travel fundraising milestone cards. One cinematic landscape image, 3:2 composition: Miami waterfront skyline at dusk, lush silhouetted palms framing neon pink and violet sunset, turquoise reflections, dark navy shadows. Stylish realistic travel poster without any text, premium adventurous Florida road trip mood. Skyline centered and readable when cropped to a narrow portrait card. No text, no logos, no watermarks.
