# Team milestone artwork

`team-reveal.jpg` is the first €400 milestone artwork for “Mūsu komanda”. Created with the built-in imagegen tool from the five member reference photos supplied by the site owner, then refined with the same tool for a closer group composition and blue/violet twilight lighting matching the existing secret artwork. The final generated PNG was exported to JPEG at its original 1086 × 1448 dimensions for the site.

The shared reveal content lives in `donations/campaign-goals.js`. The card displays the full portrait, without cropping away members, and only reveals the image once the milestone is reached.
